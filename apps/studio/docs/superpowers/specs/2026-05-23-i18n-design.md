# Frontend i18n — English / 中文

**Date:** 2026-05-23
**Scope:** Dashboard SPA (`frontend/`) only. No backend changes.

## Goal

Make the marketer-facing dashboard switchable between English and Chinese. Single language-toggle button in the sidebar footer. Default English. Choice persists in `localStorage`.

## Non-goals

- Translating backend log strings, error response bodies, or API field values.
- Translating data fetched from GeeLark / SQLite (account names, video titles, etc.).
- Auto-detecting browser language. First-time visitors get English.
- Translating the Login page UI before the user signs in (the toggle button lives in Shell, not Login). Acceptable per user.

## Stack

`react-i18next` + `i18next`. Two new runtime deps.

## Files

```
frontend/src/i18n/
  index.ts                 # i18next.init(); exports configured i18n instance
  locales/en.json
  locales/zh.json
```

`main.tsx` imports `./i18n` for side-effect init before rendering `<App />`.

## Dictionary shape

Single namespace (`translation`). Keys grouped by surface:

```json
{
  "shell":     { "brand": "...", "dashboard": "...", "accounts": "...", "videos": "...", "settings": "...", "workers": "...", "signOut": "...", "switchTo": "..." },
  "login":     { "title": "...", "subtitle": "...", "password": "...", "placeholder": "...", "signIn": "...", "signingIn": "...", "wrong": "...", "footer": "..." },
  "common":    { "loading": "...", "save": "...", "cancel": "...", "delete": "...", "confirm": "...", "close": "...", ... },
  "dashboard": { ... },
  "accounts":  { ... },
  "videos":    { ... },
  "settings":  { ... }
}
```

Keys named after their role, not their English value (e.g. `signOut` not `signOutText`).

## Language switch button

Location: `Shell.tsx` sidebar footer. Replaces or sits beside the existing "Workers 1 / Sign out" row.

Behavior:
- When `i18n.language === 'en'`, button label is `中文`. Click → switch to `zh`.
- When `i18n.language === 'zh'`, button label is `EN`. Click → switch to `en`.
- On switch: `i18n.changeLanguage(next)` + `localStorage.setItem('lang', next)`.

Styling: matches the existing footer text-button look (`text-[var(--color-ink-3)] hover:text-[var(--color-blue)]`). No flag icons, no dropdown.

## Initialization

`i18n/index.ts`:

```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import en from './locales/en.json'
import zh from './locales/zh.json'

const saved = (typeof localStorage !== 'undefined' && localStorage.getItem('lang')) || 'en'

i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, zh: { translation: zh } },
  lng: saved === 'zh' ? 'zh' : 'en',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
})

export default i18n
```

## Translation surface (files to touch)

| File | Strings |
|---|---|
| `components/Shell.tsx` | NAV labels, brand subtitle "v2.0" (no), "Workers 1", "Sign out", new toggle button |
| `Login.tsx` | All visible text (rendered before language is switchable but still translated via stored lang) |
| `components/ui.tsx` | Default button labels inside Modal / ConfirmDialog if any user-facing fallback strings exist; pass through `t()` from callers where parametrized |
| `pages/Dashboard.tsx` | Section headers, empty states, time-ago units (see below) |
| `pages/Accounts.tsx` | Column headers, action buttons, status pill labels, modal labels |
| `pages/Videos.tsx` | Same: headers, buttons, status labels, upload modal |
| `pages/Settings.tsx` | Field labels, button labels, success/error toast strings |

## Special cases

- **Toast messages** dispatched from page components — wrap call sites in `t('…')` rather than translating the Toast component itself.
- **Pluralization / counts** — use i18next's built-in `{{count}}` placeholder + `_one` / `_other` suffix if the page already shows pluralized strings. If existing copy doesn't pluralize, don't add it now (YAGNI).
- **Status pills** (`PENDING`, `INITIATED`, `SUCCESS`, `FAILURE`) — these are backend enum values. Translate the *display label*, keep the enum constant in code.
- **Dates / "x minutes ago"** — if any page formats relative time, route units through `t('common.ago.minutes', { count })`.

## Acceptance

1. Page loads in English by default for a fresh visitor.
2. Click sidebar footer toggle → entire UI flips to Chinese without reload, all visible strings are Chinese.
3. Reload → still Chinese.
4. Click toggle again → back to English; reload → still English.
5. `pytest -q` still passes (no backend changes, but rebuild check).
6. `npm run build` in `frontend/` succeeds with no TypeScript errors.
